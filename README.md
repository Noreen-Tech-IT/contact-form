# 📩 Contact Form

A simple contact form website created to practice HTML forms and CSS styling.

## 📌 Project Overview

This project was created as a practice project while learning web development. I first built the basic contact form structure using HTML and then improved its appearance using CSS.

## 🛠️ Technologies Used

* HTML5
* CSS3

## ✨ Features

* 📩 Contact form
* 📝 Form input fields
* 🔘 Submit button
* 🧭 Styled header
* 📏 Adjusted height and width using CSS
* 📐 Flexbox used for layout and alignment
* 🎨 Basic CSS styling

## 📚 What I Learned

Through this project, I practiced:

* Creating forms using HTML
* Working with form input elements
* Styling HTML elements with CSS
* Setting element height and width
* Using Flexbox for layout
* Aligning and arranging elements
* Connecting CSS with an HTML webpage

## 🚀 Future Improvements

I plan to improve this project by adding:

* JavaScript form validation
* Responsive design
* Better form styling
* Interactive form features
